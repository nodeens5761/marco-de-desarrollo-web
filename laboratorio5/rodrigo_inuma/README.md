# TechLab APF1

Proyecto demostrativo de rutas formativas desarrollado para la semana 4.

## Ejecución

1. Abrir la carpeta `techlab-apf1` en Visual Studio Code.
2. Abrir `index.html` con Live Server.
3. Probar la página en el navegador.

## Tecnologías

- HTML5
- CSS3
- JavaScript ECMAScript moderno
- Bootstrap 5.3.8
- Bootstrap Icons 1.13.1

## Requisitos implementados

- Navbar colapsable y accesible.
- Navegación interna.
- Hero responsivo.
- Tres rutas en cards.
- Tabla responsiva con cuatro filas y cuatro columnas.
- Modal reutilizable con `data-curso`.
- Formulario con validación.
- Mensaje de éxito con `role="status"` y `aria-live="polite"`.
- Restablecimiento del formulario al cerrar el modal.
- Año dinámico en el footer.
- Separación entre HTML, CSS y JavaScript.
- Imágenes locales.

## Limitación

El registro es únicamente demostrativo. No se almacena ni se envía información a un servidor.
