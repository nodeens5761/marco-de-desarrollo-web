SEMANA 1 · FUNDAMENTOS

Construye una base sólida para desarrollar en la Web

HTML aporta significado, CSS define la presentación y JavaScript incorpora comportamiento e interacción.

Domina primero los estándares web; después comprenderás mejor cualquier framework.

Tecnologías fundamentales

HTML

Estructura el contenido de una página y expresa su significado mediante elementos semánticos.

CSS

Controla la presentación, distribución, colores, tamaños y adaptación de la interfaz.

JavaScript

Permite responder a las acciones del usuario y modificar la interfaz de manera dinámica.

Herramientas del navegador

Permiten inspeccionar elementos, revisar estilos, detectar errores y analizar el funcionamiento de una web.

Buenas prácticas desde el inicio

  • Usar elementos semánticos.
  • Separar responsabilidades.
  • Diseñar para teclado y pantallas pequeñas.
  • Verificar antes de entregar.
  • Mantener archivos organizados.

Mi meta de aprendizaje

Mi meta de aprendizaje es comprender cómo trabajan conjuntamente HTML, CSS y JavaScript para desarrollar páginas web modernas, accesibles y adaptables. También busco aprender a utilizar correctamente las herramientas del navegador para detectar, analizar y solucionar errores durante el desarrollo.
