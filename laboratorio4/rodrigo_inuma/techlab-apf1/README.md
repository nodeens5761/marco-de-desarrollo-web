## Ejecución

1. Abrir la carpeta `techlab-apf1` en Visual Studio Code.
2. Instalar la extensión Live Server.
3. Clic derecho sobre `index.html` y elegir **Open with Live Server**.
4. URL local habitual: `http://127.0.0.1:5500/index.html`.

Requiere conexión a internet para cargar Bootstrap desde el CDN.

## Versiones

- Bootstrap 5.3.8 (CSS y `bootstrap.bundle.min.js`, con SRI)
- Bootstrap Icons 1.13.1

## Requisitos implementados

RF-01 a RF-10 y RC-01 a RC-10: navbar colapsable con `aria-current`, tres rutas en rejilla 1/2/3 columnas, tabla responsiva con `caption`, modal reutilizable con `data-curso`, formulario validado con mensaje en `role="status"`, reinicio al cerrar el modal y año dinámico en el footer.

Limitación conocida: el registro es una simulación; no se envía ni almacena ningún dato.
